# 娱乐游戏中心与轻松模式自定义网址设计

日期：2026-08-05

## 目标

将现有娱乐模式从固定的 2048 升级为可选择的本地游戏中心，首批提供俄罗斯方块和 2048；同时移除轻松模式强制加载且不可删除的抖音预设，让用户自行维护网址列表。两项改动都复用现有右侧工作区，不改变普通模式、终端会话或主题系统。

## 已确认的产品行为

- 保留 2048，新增俄罗斯方块。
- 首次进入娱乐模式默认打开俄罗斯方块。
- 记住用户上次选择的游戏，后续进入娱乐模式时恢复该选择。
- 轻松模式不再包含任何系统预设网页。
- 用户可以添加、选择、刷新、在系统浏览器打开和删除自己添加的网址。
- 升级后移除旧版本自动注入的抖音项，但保留用户添加的其他网址。
- 所有游戏在本地运行，不引入联网游戏或新的第三方依赖。

## 架构

### 游戏注册表

新增轻量游戏注册表。每个游戏登记稳定 ID、显示名称、操作提示和工厂函数，并统一实现以下生命周期接口：

```js
{
  mount(target),
  pause(),
  resume(),
  restart(),
  destroy(),
  getState(),
}
```

工作区控制器只管理游戏选择、可见性和生命周期，不包含具体游戏规则。每款游戏使用独立宿主元素并按需创建；切换游戏时暂停并隐藏旧游戏，显示并恢复新游戏，因此用户切回时可以继续未结束的一局。离开娱乐模式、收起终端、窗口失焦、页面隐藏或弹出遮罩时，当前游戏必须暂停。

### 俄罗斯方块模块

俄罗斯方块作为 `src/games/game-tetris.js` 独立模块，纯规则函数与 DOM 控制器分离。首版范围如下：

- 10×20 主棋盘和 7 种标准方块。
- 使用七袋随机法生成方块，显示下一块预览。
- 支持左右移动、软降、旋转和硬降。
- 完整行消除、得分、最高分、等级与随等级加速。
- 暂停、重新开始和游戏结束状态。
- 键盘控制为方向键移动、方向键上旋转、空格硬降、`P` 暂停。
- 提供可点击的屏幕控制按钮，窄面板和触控环境也可操作。
- 不在首版加入保留方块、复杂连击、联网排行或音效设置。

计时器只驱动当前活动且未暂停的俄罗斯方块。销毁实例时必须清理计时器和事件监听，避免后台继续运行。

### 2048 兼容

现有 `game-2048.js` 保持规则和分数数据兼容，仅接入游戏注册表。它继续使用自己的最高分存储键。俄罗斯方块使用独立最高分存储键，二者互不覆盖。

### 轻松模式网址数据

工作区设置升级为新版结构：

```js
{
  mode,
  companionWidth,
  sites,
  activeSiteId,
  activeGameId,
}
```

`sites` 允许为空；此时 `activeSiteId` 为 `null`。`activeGameId` 只接受注册表中的游戏 ID，缺失或无效时使用 `tetris`。

读取旧版设置时执行一次兼容迁移：精确匹配旧内置项 `id: "douyin"` 且 URL 为 `https://www.douyin.com/` 的记录会被移除；其他记录原样经过现有安全归一化后保留。用户以后仍可手动添加抖音或任何符合规则的网址。新版设置写入独立的版本化存储键，旧键只用于迁移读取。

## 界面与交互

### 娱乐模式

- 右侧工具栏将固定的“2048”标签改为游戏选择器。
- 选择器首批显示“俄罗斯方块”和“2048”，旁边的操作提示随所选游戏变化。
- 游戏内容继续位于现有右侧面板，沿用深色样式、尺寸拖动和“终端”返回按钮。
- 俄罗斯方块顶部显示名称、分数、最高分、等级、下一块和重新开始按钮；棋盘保持清晰的网格与高对比方块颜色。
- 游戏容器可聚焦，键盘焦点具有可见状态；按钮使用语义化标签，状态变化通过适度的 `aria-live` 文案提示。
- 面板较窄时缩小棋盘并将信息区紧凑排列，不产生横向页面滚动。

### 轻松模式

- 没有网址时不创建原生 WebView，显示轻量空状态：“还没有网页”，并提供明显的“添加网页”按钮。
- 工具栏保留“＋”入口。存在网址时显示站点选择器，以及删除、刷新和外部浏览器打开按钮。
- 所有用户网址都可删除。删除当前网址后选择下一项；没有剩余项时回到空状态。
- 添加成功后立即选中新网址并尝试加载，同时持久化名称、规范化 URL 和当前选择。
- 名称可留空，留空时使用域名；远程地址只允许 HTTPS，本地开发地址额外允许 `http://localhost`、`127.0.0.1` 和 `::1`。
- 进入轻松模式只加载当前用户选择的网址。没有网址时不发生网络请求，因此不会再因默认抖音阻塞体验。

## 状态与错误处理

- 站点数据读取失败、旧数据无效或本地存储不可用时，轻松模式降级为空列表，应用仍可使用。
- URL 校验失败时保留添加弹窗内容并显示明确错误，不创建 WebView。
- 网页加载失败时保留站点记录，显示失败信息，并允许重试或在系统浏览器打开。
- 网站本身网络较慢时继续显示加载状态；本功能不承诺加速第三方网站，只消除强制加载。
- 某个游戏创建失败时在游戏区域显示错误状态，游戏选择器仍可切换到另一款游戏。
- 游戏切换、窗口生命周期和浮层状态必须串行更新，避免隐藏游戏继续接收键盘或计时。

## 测试策略

采用测试驱动开发，先写失败测试，再实现最小代码。

### 自动测试

- 俄罗斯方块纯规则：七种方块生成、边界与碰撞、旋转、锁定、完整行消除、计分、等级速度和游戏结束。
- 俄罗斯方块控制器：暂停时计时器不推进、恢复后继续、硬降、重新开始和销毁后清理。
- 游戏中心：首次默认俄罗斯方块、保存并恢复选择、切换时暂停旧游戏并恢复新游戏、生命周期暂停。
- 设置迁移：删除精确的旧内置抖音项、保留其他用户网址、空列表得到 `activeSiteId: null`、无效游戏 ID 回退到 `tetris`。
- 轻松模式：空状态不创建 WebView、添加首个网址后加载、删除最后一个网址后关闭 WebView 并恢复空状态。
- 静态结构：游戏选择器、空状态按钮和必要的可访问性属性存在。
- 运行完整 `pnpm test`，并运行现有 Rust 测试与 Clippy，确认工作区行为没有回归。

### 手工验收

- 在 Tauri Debug 应用中分别进入普通、轻松和娱乐模式。
- 验证首次轻松模式无网络加载，添加、切换、删除网址均正常。
- 验证俄罗斯方块键盘和屏幕按钮、自动下落、消行、暂停、重开与游戏结束。
- 在俄罗斯方块与 2048 间来回切换，确认局面保留且只有当前游戏响应输入。
- 收起终端、切换模式、窗口失焦和重新聚焦，确认游戏与 WebView 生命周期正确。
- 拖动右侧宽度并检查窄面板布局、焦点样式和内容溢出。

## 不在本次范围

- 第三款游戏、游戏商店、插件下载或联网排行榜。
- 第三方网页的网络加速、代理、预加载或登录状态迁移。
- 对普通模式、终端核心、主题系统或 Rust 后端数据格式进行无关重构。
