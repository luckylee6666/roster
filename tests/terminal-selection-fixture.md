# 终端文字拖选验收

本夹具加载仓库随附的 xterm，并提取 `src/main.js` 中 `createSession` 的真实构造参数。上方终端保留旧鼠标策略，下方使用当前配置；仅使用合成文本，不连接 PTY，也不读取或写入系统剪贴板。

在仓库根目录启动仅监听本机的静态服务：

```sh
python3 -m http.server 4186 --bind 127.0.0.1
```

使用独立无头浏览器访问 `http://127.0.0.1:4186/tests/terminal-selection-fixture.html`，点击「运行行为回归」。追加 `?renderer=webgl` 再运行一次，默认页面覆盖图片主题使用的 DOM 渲染路径；WebGL 页覆盖纯色主题使用的 GPU 渲染路径。页面会显示每项断言与总计，出现 `FAIL` 则未通过。此夹具不计入 `pnpm test` 的测试数。

除页面内合成事件外，使用浏览器驱动的真实鼠标输入分别拖动上下两段中文：旧配置应无选区且有鼠标报告，当前配置应有完整中文选区且无鼠标报告。不要在用户正在工作的浏览器窗口或真实 CLI 会话里注入测试事件。

覆盖：鼠标上报下的普通拖选、中文复制事件、Option/Alt 交互报告与修饰符剥离、滚轮、全移动报告模式、退出和重新启用鼠标模式。复制断言使用测试 `clipboardData`，不等同于操作系统快捷键和剪贴板端到端验收；原生 WKWebView 与实体键盘仍需单独验收。

完成后停止静态服务并关闭本次独立无头浏览器。
